# Liberty Kollection

Official online store and luxury ecommerce boutique for Liberty Kollection.
"Your Look, Your Liberty."

Developed by: **RAPIDTECHPRO**

## Tech Stack
- **Framework**: Next.js 14 (App Router)
- **Styling**: TailwindCSS & Custom CSS Design System
- **State Management**: Redux Toolkit
- **Database & ORM**: MySQL & Prisma
- **Animations**: Framer Motion

## Getting Started
First, install dependencies:
```bash
npm install
```

Run the development server:
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) or configured port with your browser to view the store.
